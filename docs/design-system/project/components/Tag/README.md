# Tag

An engraved label stamped onto a row: item kind, step numbers and small states.

- `hw-tag` for item kinds at the end of a list row: LOGIN, ALIAS, CARD, NOTE, ID, PASSKEY, PASSWORD. Kinds are told apart by the word, not by colour.
- `hw-tag--go` for a positive state ("This device", "On", "Now"); `hw-tag--warn` for a difference that needs a look ("Differs").
- One or two words in the `tag` style, mono capitals.
- Keyboard keys use `hw-kbd` instead: a small raised keycap ("Ctrl", "F").
