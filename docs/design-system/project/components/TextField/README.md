# TextField

Labelled single-line input for create and edit forms.

- Always give a visible `label`; placeholders are examples ("name@example.com"), never the label.
- `hint` for helpful context, `error` for what went wrong and how to fix it ("Enter a website, like github.com").
- Use `mono` for passwords, card numbers and codes. Pass an `IconButton` as `trailing` for generate or reveal actions.
