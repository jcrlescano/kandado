# Logo

The Kandado padlock mark, alone or with the wordmark.

- Use the wordmark (`wordmark`) in the desktop sidebar header, onboarding and the unlock screen; the bare mark in the extension header, favicons and tight spaces.
- The mark always draws in `brass`; the word in `ink`. Do not recolour, outline or put it on a brass fill.
- Keep clear space of half the mark's height on every side.
- This is a proposed first mark. When final logo files exist, add them as a Logos asset group and keep this component in step.
