# Logo

The Kandado padlock mark and the KANDADO logotype.

- Draw the mark inline so it follows the theme: a `hw-logo-body` rounded rectangle (green), two `hw-logo-hole` shapes for the keyhole (body colour) and a `hw-logo-shackle` path (ink stroke). Static SVGs for light and dark grounds are in the Logos assets.
- Closed shackle = locked or in use. The open shackle (raised on one side) appears only on sign-in and signed-out screens.
- Logotype: KANDADO in `mono`, weight 600, letter-spacing 0.18em, beside the mark at 26–30px tall. Use the mark alone in the extension header, the in-page field badge and favicons.
- Don't recolour the body, outline the mark or put it on a green fill. Keep clear space of half the mark's height.
