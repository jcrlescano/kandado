# Icon

Kandado's 24px outline icon set, drawn in `currentColor` with a 1.75px stroke.

- Pass `name` from the set (see `ICON_NAMES`); `size` 16 in dense rows, 20 in buttons, 24 in navigation.
- Colour comes from CSS `color`: `ink` by default, `ink-muted` for supporting icons, a kind hue only inside `ItemIcon`.
- Give `label` only when the icon stands alone and carries meaning; otherwise it is hidden from assistive tech.
- Never mix in filled icons, emoji or icon fonts.
