# Badge

Short status label for Monitor results, strength and counts.

- Tones: `danger` (Breached, Weak), `warning` (Reused, Missing 2FA, Expiring), `teal` (Healthy, Strong), `brass` (Shared, Owner), `neutral` (counts, plain tags).
- danger, warning and teal carry an icon by default so state never rests on colour alone. Keep the word, too.
- One or two words, sentence case.
