# IconButton

Square icon-only button for copy, reveal, more and toolbar actions.

- `label` is required: it is the tooltip and the accessible name ("Copy password", not "Copy").
- `ghost` (default) inside rows and fields; `secondary` in toolbars; `primary` only for the mobile create button.
- `sm` (32px) inside fields and rows, `md` (40px) in toolbars, `lg` (48px) on mobile.
