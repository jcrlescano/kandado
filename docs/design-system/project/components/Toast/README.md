# Toast

Brief confirmation that floats above the UI, bottom-centre on desktop and mobile, top of the extension popup.

- Confirm copies with the clear time: "Password copied. Clears in 60 s."
- One `action` at most ("Undo" after move to trash). Auto-dismiss after 4 s; stay while hovered.
- `tone="danger"` only for failures ("Couldn't sync. Retrying.").
