# VaultChip

A vault as a selectable chip: name, colour, optional count.

- Each vault picks one hue (`tone`: brass, teal, coral, sky, plum, moss) and an icon; the chip shows them on the hue's soft ground.
- `active` marks the vault being viewed. `dropdown` turns it into the vault switcher in the extension and mobile headers.
- Name vaults by purpose ("Personal", "Family", "Work").
