# ItemIcon

The coloured tile that tells an item's kind at a glance.

- `kind`: login (teal key), alias (moss @), card (coral), note (sky), identity (plum), password and passkey (brass).
- Logins may show the site's initial via `letter` when no favicon is loaded; never fetch favicons by default (privacy), offer it as a setting.
- 40px in lists, 32px dense, 56px on the item detail header.
