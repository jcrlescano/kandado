# Logos

The Kandado padlock mark as static files. `kandado-mark-light.svg` is for light grounds (green #1F5A4A body, graphite #23272B shackle, enamel #E4E0D8 keyhole). `kandado-mark-dark.svg` is for dark grounds (green #46A585 body, #ECE9E2 shackle, #121517 keyhole). In product UI, draw the mark inline with the `hw-logo-*` classes so it follows the theme.
