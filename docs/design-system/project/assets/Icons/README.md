# Icons

The Hardware icon set, one file per icon: `<name>.svg`, 24 × 24, `fill="none"`, `stroke="currentColor"`, `stroke-width="1.9"`, round caps and joins. Dots are `fill="currentColor"`. Shown here in black because a picture cannot follow the text colour; in the apps the ink is the surrounding text colour (`ink`, `on-green`, `danger`…). The desktop app draws an SVG as a one-colour mask, so any single ink works there.

`icons.json` has the same icons as data: `viewBox`, `strokeWidth`, `names` (in order) and `icons` (name to the inner markup of the `<svg>`). Guidelines are on the Icon component.
